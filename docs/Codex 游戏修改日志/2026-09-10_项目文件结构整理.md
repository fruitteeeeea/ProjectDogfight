### 核心结构 / 主要改动

新增或调整：

- `assets/`：集中保存音频、品牌素材、字体和各类精灵；第三方或来源不明确的素材文件名保持原样。
- `game/`：保存正式运行的场景与脚本，并按 `ai / aircraft / autoload / camera / combat / core / ui / world` 分组。
- `resources/`：保存共享数据资源和主题。
- `tests/`：将触控、VirtualJoystick 和敌机测试集中到 `integration` 与 `manual`。
- `third_party/limboai_demo/`：隔离 LimboAI 演示场景、教程行为树、素材和许可证。
- `README.md`：补充项目结构、命名规则、入口场景、Autoload 和测试方式。

核心流程：

```text
project.godot / 主菜单
  -> game/core/main_game.tscn
    -> game/aircraft + game/combat + game/world
    -> game/ai + game/ui + game/camera
    -> assets + resources
```

补充说明：

- `Unit/Prototype/bg.tscn` 已归入世界背景，敌机生成器归入世界生成模块，游戏速度控件归入 HUD，不再作为临时原型处理。
- 游戏实际使用的行为任务保留在 `game/ai/tasks`；LimboAI 教程树和演示内容位于 `third_party/limboai_demo`。
- `.uid` 文件随脚本保留和迁移，确保脚本与场景资源身份稳定。
